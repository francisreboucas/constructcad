# Security Policy

## Supported versions

ConstructCraft is in early development. Security fixes are applied to the latest release and the `main` branch only.

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/francisreboucas/constructcraft/security/advisories/new) or by email to francisreboucas@gmail.com.

Include as much of the following as you can:

- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept (for example a crafted `.ccad` file).
- The affected version or commit and your operating system.

You can expect an acknowledgement within 7 days. We will keep you informed while a fix is prepared and credit you in the release notes unless you prefer to remain anonymous.

## Scope

Of particular interest are issues where opening an untrusted project file could cause code execution, memory corruption, data loss outside the project file, or uncontrolled resource consumption.
